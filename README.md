## 常见问题

**海外云服务器需要备案吗？**
不需要ICP备案，购买后即可上线。但如果你把域名解析回中国大陆的服务器，那个域名仍然需要备案。

**香港和新加坡怎么选？**
大陆访客为主选香港，延迟更低；东南亚客户为主选新加坡。两边都有业务，可以各买一台小配置做节点。

**轻量应用服务器和CVM有什么区别？**
轻量是固定套餐、含流量包、管理简单，适合单站点和小项目；CVM配置自由、支持弹性升降配、能和VPC内其他云产品内网互通，适合业务系统。预算有限且需求简单，轻量够用；要长期扩展，直接上CVM。

**能安装Windows系统吗？**
可以，轻量和CVM都支持Windows镜像，但Windows对配置要求更高，2核2G起步比较稳妥，具体授权和费用以购买页为准。

**月流量用完了会怎样？**
轻量套餐的流量包用完后通常会被限速或转为按量计费，具体规则写在套餐说明里，购买前确认一下。
